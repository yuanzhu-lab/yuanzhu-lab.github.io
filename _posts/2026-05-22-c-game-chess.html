A self-coded C++ project in Apr 2022.

Chess

This project is a Windows console–based Chinese Chess application. It implements full movement rules and supports peer-to-peer online matches using C++ and WinSock. Two players on the same network can play against each other.

The most interesting feature is its support for network play and cheat codes.
