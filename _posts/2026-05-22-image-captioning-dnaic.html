My undergraduate thesis, completed in Jun 2025.

DNAIC

Pipeline

Data Preparation

The dataset should be placed in the `mscoco/` directory mscoco/ |--feature/ |--coco2014/ |--train2014/ |--value2014/ |--test2014/ |--misc/ |--sent/ |--txt/

Download link: mscoco

Pre-trained Models Preparation

Pre-trained models should be placed in the `pretrained_models/` directory pretrained_models/ |-- mplug/ |-- swin-large-patch4-window12-384/ |-- vit/

Download link: pretrained_models

Training Process

The model can be trained on NVIDIA GPU with CUDA support or Apple Silicon with MPS support (CPUs are not recommended).

1. Environment Setup

Python 3.12 pip install -r requirements.txt

2. Training Command bash experiments/train.sh

Evaluation

1. Evaluation Script bash experiments/eval.sh

2. Evaluation Metrics Image Captioning: BLEU, METEOR, ROUGE-L, CIDEr Speed: Latency, SpeedUp

Download link: DNAIC-base-0.2B

Inference

1. Inference Performance bash experiments/inference.sh

2. WebUI A Gradio-based web UI is also provided for users to perform inference through a graphical interface. python webui.py
