# yuanzhu-lab.github.io

Source of https://yuanzhu-lab.github.io, built by GitHub Pages (Jekyll).

- Posts: `_posts/` (HTML bodies wrapped in `{% raw %}` so code samples are left alone)
- Category pages: `category/<slug>/index.html`, nav in `_config.yml`
- Theme: `_layouts/`, `_includes/`, `assets/css/site.css`
- Downloads: `assets/files/`; files over 100 MB live in the `files` release

Local preview: `bundle install && bundle exec jekyll serve`
